🧬 Skin Disease Detection System
Machine Learning–Based Medical Image Classification Web Application
🔍 Project Summary

The Skin Disease Detection System is an end-to-end machine learning application that classifies skin diseases from images using image preprocessing and a trained ML model. The project demonstrates real-world application of AI in healthcare, covering the full ML lifecycle: data handling, model training, inference, and web deployment.
This project highlights practical skills in Python, Machine Learning, Computer Vision, and Flask-based deployment.

💡 Problem Statement

Early identification of skin diseases is critical, yet manual diagnosis can be time-consuming and resource-intensive. This project aims to automate preliminary skin disease detection using machine learning, providing fast and consistent predictions from image data.

Built an image classification pipeline for skin disease detection
