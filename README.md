
# 🧬 Skin Disease Detection System  
### End-to-End Machine Learning Web Application for Medical Image Classification

---

## 📌 Overview

The **Skin Disease Detection System** is an end-to-end **machine learning–based web application** that predicts skin diseases from uploaded images.  
The project demonstrates the practical application of **AI/ML, computer vision, and web deployment** in the healthcare domain.

It covers the complete ML workflow — **data preprocessing, model training, inference, and deployment using Flask**.

---

## 🎯 Motivation

Skin diseases are often diagnosed through visual inspection, which can be time-consuming and subjective.  
This project aims to provide an **automated, consistent, and scalable solution** for preliminary skin disease classification using machine learning.

---

## 🧠 System Workflow

1. User uploads a skin image via web interface  
2. Image is preprocessed (resizing, normalization)  
3. Trained ML model performs classification  
4. Predicted skin disease is displayed to the user
